# rork-hustlexp-gig-marketplace-app-796

Mobile-client repository for HustleXP, one managed local-work transaction network.

The [HustleXP Business and Universal V1 Charter](https://github.com/Sebdysart/HUSTLEXP-DOCS/blob/main/governance/HUSTLEXP_BUSINESS_AND_UNIVERSAL_V1_CHARTER.md) controls company, product-lane, category, provider, lifecycle, service-promise, and money policy. Implementation detail lives under [`expo/`](expo/README.md).

Charter v1.1.0 makes `VERIFIED_TRADE_BUSINESS` a first-class provider class in an `ACTIVE_GATED` managed marketplace lane. Client copy must not describe regulated trades as future, referral-only, or external to HustleXP; exact payment capabilities remain gated and frozen.

This repository documentation cannot authorize provider eligibility, protected merges, deployment, or production money behavior. Production payment creation remains frozen.
